# The Pantheon Zaibatsu — V1

Static GitHub Pages prototype.

## Publish
1. Upload `index.html`, `styles.css`, `script.js`, and the entire `assets` folder to the root of the `thepantheonzaibatsu` repository.
2. In GitHub: Settings → Pages.
3. Under Build and deployment choose **Deploy from a branch**.
4. Choose branch **main** and folder **/(root)**, then Save.
5. GitHub will show the published Pages address when deployment completes.

## Later
Replace the temporary remote hero photograph in `styles.css` with a locally hosted TPZ image before final launch.
